# **App Name**: CogniFlow

## Core Features:

- Configurable Sub-Tests & Question Bank: Supports 6 predefined sub-tests (Language, Calculations, General Knowledge, Pattern Recognition, Abstraction, Spatial Reasoning) with a bank of 228 questions, and allows easy configuration for content changes.
- Generative Calculation Problems: Automatically generates a variety of calculation questions, including basic arithmetic, percentages, and word problems, using an algorithmic tool.
- Timed Sub-Test Interface: Presents questions for each sub-test with a visible 7-minute countdown timer that automatically transitions to the next sub-test upon expiration.
- Interactive Question & Answer Submission: Provides input fields for user answers and a 'Save Answer or Continue' button to submit responses for each question.
- Simulated Save Failure & Retry Mechanism: Implements a feature where saving an answer will occasionally 'fail' (e.g., due to simulated network or validation issues), requiring the user to re-attempt submission until it's successfully saved, ensuring robust error handling.
- Overall Test Progress Display: Displays current sub-test progression, providing users with a clear sense of their position within the entire exam tryout.

## Style Guidelines:

- Primary accent color: A professional and focused medium blue (`#2966A3`), signifying clarity and intellect.
- Background color: A very light, calming off-white with a subtle blue tint (`#EEF2F4`), providing an uncluttered canvas for concentration.
- Accent color: A vibrant cyan (`#2CF3F3`) for interactive elements, highlights, and urgent information like the timer, drawing attention without distraction.
- All text (headlines and body): 'Inter' (sans-serif) for its neutral, modern, and highly legible appearance, suitable for diverse exam content.
- Minimalist, line-art icons for navigation, timers, and answer submission, ensuring clarity and unobtrusiveness.
- Clean, focused single-question-per-view layout with ample whitespace to minimize visual clutter and emphasize the task at hand. Clear separation for sub-test sections.
- Subtle and quick transition animations for changing questions and sub-tests, ensuring a smooth, non-distracting user flow. Dynamic timer updates should be clear and visually calm.
